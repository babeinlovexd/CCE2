# Custom Calendar Engine (CCE)

A complete, standalone Python desktop GUI application for worldbuilders to create custom, hierarchical calendar/time systems and track story events across multiple planets.

## Features
- **Universal Ticks:** Base time unit that all other units are built upon.
- **Custom Time Hierarchies:** Define any time system (e.g. 10 hours a day, 100 minutes an hour).
- **Multi-Planet Support:** Track time synchronously across multiple planets with different day/year lengths.
- **Custom Eras, Months, Weekdays:** Completely flexible calendar structures.
- **Holidays & Leap Rules:** Complex scheduling for special days and leap years.
- **Astronomy:** Track suns (binary/trinary) and moon phases.
- **Event Tracking:** Create and visualize events on the calendar, synchronized across planets.

## Running the Application
```bash
python main.py
```

## Building the Executable
```bash
./build.sh
```
