# Chronix – High Priority Roadmap & TODO

Die folgenden Features sollen in künftigen Versionen von **Chronix** umgesetzt werden, um die Anwendung zu einem führenden Profi-Werkzeug auszubauen:

- [x] ~~**1. Visueller Timeline-Gantt-Viewer**~~ (✅ **Umgesetzt in v1.1**)
   * Ergänzend zum Monatsraster eine vertikale oder horizontale Gantt-Chart-Timeline im Viewer, in der Handlungsstränge ("Parallel-Storylines") pro Kategorie oder Standort als eigene Spuren/Lanes dargestellt werden.

- [ ] **2. Interactive Map / Location Integration**
   * Verknüpfung von Ereignis-Ortseingaben mit hochgeladenen Bild-Karten (Worldmaps). Bei Auswahl eines Tages oder Events leuchtet der entsprechende Handlungsort auf der Karte auf.

- [ ] **3. Mondphasen-Grafiken**
   * Dynamische grafische Renderings (Vektorgrafiken / Moon Phase Icons: 🌑 🌒 🌓 🌔 🌕) direkt in den Kalenderzellen und Tagesdetails anstelle reiner Prozent- und Textangaben.

- [ ] **4. Auto-Updater Integration**
   * Leichtgewichtige Auto-Update-Funktion (z. B. via GitHub Releases API / PyUpdater), damit Nutzer Aktualisierungen nahtlos direkt in der Anwendung installieren können.

- [ ] **5. Erweiterte Import/Export-Formate**
   * Export nach **iCal (`.ics`)** zur Synchronisation mit realen Kalender-Apps sowie erweiterte Exportmöglichkeiten für **JSON, CSV** und **druckfähige PDF-Jahreskalender**.
